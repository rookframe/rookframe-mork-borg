# Character HUD artwork

These assets reproduce the approved revision-8 MÖRK BORG HUD authority in
`rookframe-godot/docs/product/mockups/character-hud/` at host source
`b70bdede78a5ea4d32800353061bca7f3175c673`.

The Ability/category outlines use the authority's `mork-ui.js` path data.
Attacks and Items use its existing Tabler swords and backpack assets (MIT,
Copyright Paweł Kuna; see the host's vendored icon credits and Tabler license).
The faceted Dice emblem is the authority's existing `dice-emblem.svg`; its face
number is authored as a native Label because Godot's SVG importer omits text.
The three Dice frames reproduce the authority's form-factor silhouettes and
palette. They do not introduce a new visual language or Prop.
